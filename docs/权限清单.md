# 系统权限清单

> 本清单与前端页面（`flow-web` 菜单/按钮）保持一致，由后端 `PermissionDataInitializer`（`@Order(12)`）在服务每次启动时**全量重建**写入操作权限数据表。
>
> 清单基准日期：2026-08-13 ｜ 静态权限合计：**144 项**（菜单 37 + 按钮 89 + 数据权限 18）
>
> 前端所有列表页的行操作按钮（除「详情/查看」类外）均已接入 `hasPerm()` 权限控制，各列表按钮与 permKey 对应关系见第三章。

---

## 一、权限体系说明

### 1.1 数据表

| 数据表 | 说明 |
| --- | --- |
| `sys_permission` | 操作权限表：菜单、按钮、数据权限统一定义 |
| `sys_role_permission` | 角色-权限关联表 |
| `sys_data_permission` | 角色级数据范围表（`data_scope`：1-全部，2-本部门，3-本部门及子部门，4-仅本人） |

### 1.2 权限类型（`perm_type`）

| 类型 | 含义 | 前端使用方式 |
| --- | --- | --- |
| 1 | 菜单 | `BasicLayout` 侧边栏菜单过滤、路由守卫 `meta.permKey` 校验 |
| 2 | 按钮 | 页面内 `hasPerm('xxx')` 控制按钮/操作显隐 |
| 3 | 数据权限 | 「查看模块全部数据」，后端 `PermissionEvaluator.canViewAllModuleData` 判定 |

### 1.3 初始化与生效机制

- 后端每次启动全量重建静态权限（删除旧记录后重建），**运行时动态产生的 `model-data:*` 权限及角色绑定予以保留**。
- `system_admin`（三员之系统管理员）在 `/api/v1/auth/info` 返回通配权限 `["*"]`，前端 `hasPerm` 对管理员直接放行；普通角色依赖 `sys_role_permission` 中的具体绑定生效。
- 合同台账权限种子 `EmsContractPermissionInitializer` 幂等补齐（已并入本清单，重复执行无副作用）。

permKey 规则：`{模块菜单Key}:data-all`。持有该权限的用户可查看对应模块的**全部数据**（不受部门/创建人范围限制）。

**后端判定入口**：`PermissionEvaluator#canViewAllModuleData(userId, modulePermKey)`，满足任一条件即放行：

1. 用户任一角色的数据范围为「全部」（`sys_data_permission.data_scope=1`）；
2. 用户持有该模块的 `{modulePermKey}:data-all` 权限。

### 4.2 角色级数据范围（sys_data_permission 种子）

| 角色 | roleKey | 数据范围 |
| --- | --- | --- |
| 系统管理员 | `system_admin` | 1-全部数据 |
| 安全管理员 | `security_admin` | 2-本部门数据 |
| 审计管理员 | `audit_admin` | 4-仅本人数据 |

> 数据范围字典 `data_scope` 取值：1-全部数据、2-本部门数据、3-本部门及子部门数据、4-仅本人数据。

## 五、角色默认权限分配

| 角色 | roleKey | 分配范围 |
| --- | --- | --- |
| 系统管理员 | `system_admin` | 全部权限（含动态 model-data 权限）；接口层返回通配 `["*"]` |
| 安全管理员 | `security_admin` | `system` 及 `system:*` 全部项（后台管理 32 项） |
| 审计管理员 | `audit_admin` | `system:log*` + `monitor*` + `dashboard` + `system:admin:audit`（只读 14 项） |

> 其余业务角色（如 `tc_approver`、`tc_observer`、`data_role` 等）不预置权限，通过「角色管理 → 权限分配」按需授予。

## 六、动态业务数据权限（model-data，运行时生成）

数据模型生成物理表时，由 `ModelMenuPermissionService` 幂等创建并绑定 `system_admin`：

| 权限名称 | permKey 规则 | 类型 |
| --- | --- | --- |
| 业务数据（根菜单） | `model-data` | 菜单 |
| 模型子菜单 | `model-data:{modelKey}` | 菜单 |
| 查看/新增/编辑/删除 | `model-data:{modelKey}:view` / `:create` / `:update` / `:delete` | 按钮 |

> 权限重建时 `model-data*` 相关记录不会被清除，保证动态菜单与权限持续有效。
