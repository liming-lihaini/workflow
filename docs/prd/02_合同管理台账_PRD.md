## 背景

### 需求背景

环境监测机构在经营过程中涉及大量合同：与客户签订的检测服务合同（收入类），以及与外协单位、设备供应商、耗材供应商签订的采购/外协合同（支出类）。目前合同的签订信息、收付款计划与实际收付款记录分散在线下表格中，存在以下问题：

1. **信息分散**：合同基本信息、收付款约定、实际收付款流水无统一台账，查询统计困难；
2. **应收应付不透明**：管理层无法实时掌握"应收未收、应付未付"的资金敞口；
3. **收付款失控**：无节点化的收付款计划管理，回款进度、付款进度缺乏跟踪与提醒，易漏收漏付；
4. **与业务脱节**：合同与检测委托、客户档案相互独立，无法追溯"合同 → 委托 → 回款"的业务闭环。

### 需求发起人

经营管理层 / 财务部门

### 需求预期效果

构建一套**合同管理台账**，提供以下核心能力：

1. **合同信息管理**：统一登记合同基础信息、金额、期限、相对方，支持全生命周期状态管理；
2. **收付款节点管理**：按合同约定拆分收/付款节点（期数），形成应收/应付计划；
3. **支付与收款登记**：逐笔登记实际收款、支付流水，自动核销对应收付款节点，实时计算履约进度；
4. **台账与提醒**：应收应付汇总、逾期未收付提醒，辅助资金计划决策。

## 产品规划

### 产品定位、目标、愿景

**产品定位**：面向环境监测机构经营管理的合同资金台账模块（环境监测管理 EMS 子域）

**产品目标**：
- 合同信息 100% 线上化，台账可查、可搜、可统计
- 收付款节点计划化，每笔实际收付款可核销到具体节点
- 应收/应付敞口实时可见，逾期节点自动标红提醒
- 与客户管理、检测委托打通，支持业务穿透追溯

**产品愿景**：成为机构合同履约与资金管理的唯一可信数据源

### 产品目标受众

- **合同管理员/经营专员**：录入与维护合同信息、收付款节点
- **财务人员**：登记收款、支付流水，对账核销
- **业务部门负责人**：查看本部门合同履约与回款进度
- **管理层**：查看应收应付汇总台账

## 功能详述

### 1. 合同信息管理

#### 1.1 功能描述

提供合同台账列表与合同录入/编辑能力，支持按合同类型区分**收入合同**（与客户签订，产生收款）与**支出合同**（与供应商/外协单位签订，产生付款）。

#### 1.2 合同列表

| 能力 | 说明 |
|------|------|
| 查询条件 | 合同编号（模糊）、合同名称（模糊）、合同类型、合同状态、相对方（模糊）、签订日期区间、负责人 |
| 列表字段 | 合同编号、合同名称、合同类型、相对方、合同金额(元)、已收/已付金额、收付进度、签订日期、到期日期、合同状态、负责人 |
| 排序 | 默认按创建时间倒序，支持按金额、签订日期排序 |
| 操作 | 新建、编辑、删除（仅草稿）、详情、作废 |
| 收付进度列 | 进度条展示：已收付金额 / 合同金额；逾期节点数以红色角标提示 |

#### 1.3 合同信息字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 合同编号 | 文本 | 是 | 系统按规则生成（HT + yyyyMMdd + 4位流水），允许手工修改，唯一 |
| 合同名称 | 文本 | 是 | 最长 100 字 |
| 合同类型 | 字典 | 是 | 收入合同 / 支出合同（dictCode: `contract_type`） |
| 相对方 | 关联选择 | 是 | 收入合同关联**客户**（复用客户管理）；支出合同录入供应商名称（文本，支持后续扩展供应商档案） |
| 合同金额(元) | 金额 | 是 | ≥ 0，保留两位小数 |
| 签订日期 | 日期 | 是 | - |
| 生效日期 | 日期 | 否 | 默认同签订日期 |
| 到期日期 | 日期 | 否 | 用于到期提醒 |
| 负责人 | 人员选择 | 是 | 系统内用户 |
| 关联检测委托 | 关联选择 | 否 | 收入合同可关联一个或多个检测委托（多选），用于业务穿透 |
| 付款方式 | 字典 | 否 | 一次性 / 分期（dictCode: `contract_pay_mode`），选择"分期"时收付款节点至少 2 期 |
| 合同附件 | 附件 | 否 | 合同扫描件等，复用附件上传组件（bizType='contract'） |
| 备注 | 长文本 | 否 | - |
| 合同状态 | 系统字段 | - | 草稿 / 执行中 / 已完结 / 已中止 / 已作废 |
| 创建人/创建时间、更新人/更新时间 | 系统字段 | - | 系统自动记录，展示真实姓名 |

#### 1.4 状态流转规则

| 操作 | 前置状态 | 目标状态 | 规则 |
|------|---------|---------|------|
| 提交 | 草稿 | 执行中 | 必填校验通过；收付款节点已维护（至少 1 个节点） |
| 自动完结 | 执行中 | 已完结 | 全部收/付款节点核销完成（已登记金额 ≥ 节点金额）时系统自动流转 |
| 中止 | 执行中 | 已中止 | 需填写中止原因；中止后禁止新增收付款登记 |
| 恢复 | 已中止 | 执行中 | - |
| 作废 | 草稿/执行中 | 已作废 | 需二次确认（Modal.confirm）；已发生过收付款登记的合同不允许作废，仅可中止 |
| 编辑 | 草稿 | 草稿 | 执行中合同仅允许编辑备注、附件、到期日期等非核心字段 |
| 删除 | 草稿 | - | 级联删除收付款节点；已提交过的合同不可删除 |

#### 1.5 合同详情页

独立详情页（路由打开），布局与现有详情页（委托详情）保持一致：

- **信息头（.page-toolbar）**：返回按钮 + 合同名称 + 合同编号，吸顶固定，浅蓝底 `#f0f4f9`；
- **基本信息卡片**：字段描述列表（Descriptions）+ 合同说明 + 合同附件；
- **收付款节点卡片**：节点计划列表 + 每节点核销进度（详见第 2 章）；
- **收付款记录卡片**：全部收/付款流水时间线/表格；
- **关联业务卡片**：关联检测委托列表，点击穿透跳转委托详情；
- **操作记录卡片**：合同的新建/编辑/提交/中止/作废处置轨迹。

### 2. 收付款节点管理

#### 2.1 功能描述

将合同金额按期拆分为若干**收付款节点**（收入合同为收款节点，支出合同为付款节点），形成应收/应付计划，作为实际收付款登记的核销对象。

#### 2.2 节点字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 期数 | 数字 | 是 | 自动生成（1、2、3…），可调整顺序 |
| 节点名称 | 文本 | 是 | 如"预付款""进度款""验收款""质保金" |
| 计划金额(元) | 金额 | 是 | > 0；**所有节点计划金额合计必须等于合同金额**，保存时校验 |
| 计划日期 | 日期 | 是 | 约定收/付款日期，用于逾期判定 |
| 节点说明 | 文本 | 否 | 付款条件说明，如"报告交付后 30 日内" |
| 节点状态 | 系统字段 | - | 待收/待付（未登记）→ 部分收/部分付 → 已收讫/已付讫 |

#### 2.3 业务规则

1. 节点在合同"草稿/执行中"状态下可增删改；合同已完结/中止/作废时只读；
2. 节点调整金额时校验：`Σ节点计划金额 = 合同金额`，不等时禁止保存并提示差额；
3. 已产生收付款登记的节点不允许直接删除，须先删除/调整对应登记；
4. 节点核销进度 = 该节点下已登记金额合计 / 节点计划金额，≥100% 置为"已收讫/已付讫"；
5. **逾期判定**：计划日期 < 当前日期 且节点未收讫/付讫，节点标记"逾期"红色标签，合同列表以角标汇总提示。

### 3. 收款登记（收入合同）

#### 3.1 功能描述

财务对收入合同逐笔登记实际收款流水，可指定核销一个或多个收款节点。

#### 3.2 登记字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 收款日期 | 日期 | 是 | 默认当天 |
| 收款金额(元) | 金额 | 是 | > 0 |
| 收款方式 | 字典 | 是 | 银行转账 / 支票 / 现金 / 其他（dictCode: `pay_method`） |
| 交易流水号 | 文本 | 否 | 银行回单号 |
| 核销节点 | 多选分摊 | 是 | 从本合同未收讫节点中选择，将本次金额分摊到各节点（默认按节点顺序自动分摊，可手工调整），分摊合计必须等于收款金额 |
| 收款凭证 | 附件 | 否 | 银行回单图片/PDF（bizType='contract_receipt'） |
| 经办人 | 人员选择 | 是 | 默认当前用户 |
| 备注 | 文本 | 否 | - |

#### 3.3 业务规则

1. 仅"执行中"状态的合同可登记收款；
2. 登记保存后合同"已收金额"自动累加，节点核销状态自动重算；
3. 支持**删除/撤销登记**：删除后回退节点核销进度与合同已收金额；若删除导致合同不再满足完结条件，状态由"已完结"回退为"执行中"；
4. 累计收款金额不得超过合同金额，超出时阻止保存并提示。

### 4. 支付登记（支出合同）

#### 4.1 功能描述

对支出合同逐笔登记实际支付流水，核销付款节点。字段与规则与收款登记对称：

| 字段 | 必填 | 说明 |
|------|------|------|
| 支付日期 | 是 | 默认当天 |
| 支付金额(元) | 是 | > 0 |
| 支付方式 | 是 | 复用 `pay_method` 字典 |
| 交易流水号 | 否 | - |
| 核销节点 | 是 | 分摊规则同收款登记 |
| 支付凭证 | 否 | 付款回单附件 |
| 经办人 | 是 | 默认当前用户 |
| 备注 | 否 | - |

**业务规则**：与收款登记一致（状态限制、核销回退、累计不超合同金额）。

### 5. 台账汇总与提醒

#### 5.1 台账统计卡片（列表页顶部）

| 指标 | 口径 |
|------|------|
| 合同总数 / 执行中数 | 按状态统计 |
| 应收总额 | 收入合同金额合计 |
| 已收总额 / 应收未收 | 已收款合计 / 应收总额 − 已收总额 |
| 应付总额 | 支出合同金额合计 |
| 已付总额 / 应付未付 | 已付款合计 / 应付总额 − 已付总额 |
| 逾期节点数 | 全部逾期收付款节点数（红色醒目展示） |

#### 5.2 提醒规则

- 收付款节点逾期：合同列表行逾期角标 + 节点列表红色"逾期"标签；
- 合同到期前 30 天：详情页到期日期黄色提示（仅提示，不阻断）。

### 6. 业务关联与穿透

- 收入合同可关联检测委托（多选）；合同详情页展示关联委托列表，点击跳转委托详情；
- 委托详情页预留"关联合同"展示区（有关联时显示合同编号链接，点击跳回合同详情）。

## 非功能性需求

1. **性能**：台账列表分页查询（默认 20 条/页），支持万级合同数据秒开；
2. **数据一致性**：收付款登记与节点核销、合同已收付金额在同一事务内更新，删除登记时级联回退；
3. **审计**：合同与收付款的关键操作写入操作记录（参照委托操作历史模式），含操作人真实姓名与时间；
4. **兼容**：前端复用现有组件规范（a-card / a-descriptions / 附件卡片网格 / 详情页吸顶信息头），风格与 EMS 模块一致。

## 开放问题

1. 支出合同的相对方是否需要立即建立供应商档案（本期暂以文本录入）？
2. 合同是否需要接入流程引擎做签订审批（当前按台账直录设计，审批流程列入三期）？
3. 收付款登记是否需要与财务系统/银行流水对接（本期手工登记 + 凭证附件）？
