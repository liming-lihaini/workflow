# TC01 - 认证管理测试用例

## 模块信息
- **页面路径**：flow-web/src/views/login/index.vue
- **后端接口**：AuthController（/api/v1/auth/*）
- **API 文件**：flow-web/src/api/auth.js
- **优先级**：P0
