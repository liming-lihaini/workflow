# 系统管理模块测试方案

## 1. 测试概述

### 1.1 测试目标
验证系统管理模块全部功能的正确性、完整性和稳定性，确保各子模块在正常及异常场景下均能按预期工作。

### 1.2 测试范围
系统管理模块共包含 **7 个子模块**，覆盖 13 个后端 Controller、8 个前端页面：

| 序号 | 子模块 | 前端页面 | 后端 Controller | 路由 |
|------|--------|----------|----------------|------|
| 1 | 认证管理 | login/index.vue | AuthController | /login |
| 2 | 部门管理 | dept.vue / dept-detail.vue | DeptController | /system/dept |
| 3 | 用户管理 | user.vue / user-detail.vue | UserController | /system/user |
| 4 | 角色管理 | role.vue | RoleController + PermissionController | /system/role |
| 5 | 数据字典 | dict.vue | DictController | /system/dict |
| 6 | 日志管理 | log.vue | LogController | /system/log |
| 7 | 三员管理 | admin.vue | AdminController + TripleAdminInitializer | /system/admin |

### 1.3 测试环境

| 项目 | 配置 |
|------|------|
| 后端 | Spring Boot 3.x + SQLite + MyBatis-Plus |
| 前端 | Vue3 + Ant Design Vue 4.x + Vite |
| 浏览器 | Chrome 120+、Edge 120+ |
| 测试账号 | admin / 123456（系统管理员） |

### 1.4 测试数据
- 基础数据：33 个部门（3 级树形）、165+ 用户（水浒传人物）、7 个角色、79 个权限、13 个字典类型、53 个字典项
- 运行时数据已清除（访问日志、操作日志、流程实例等均为空）

## 2. 测试策略

### 2.1 测试类型

| 类型 | 说明 | 覆盖方式 |
|------|------|----------|
| 功能测试 | 验证各功能点正确性 | 每个功能逐项验证 |
| 边界测试 | 空值、超长、特殊字符 | 表单必填项、长度限制 |
| 异常测试 | 非法参数、越权访问 | API 层 + 前端层 |
| 兼容性测试 | 不同浏览器表现 | Chrome + Edge |
| UI 测试 | 布局、交互、响应式 | 人工验证 |

### 2.2 测试优先级

| 优先级 | 模块 | 原因 |
|--------|------|------|
| P0 | 认证管理 | 系统入口，阻断性 |
| P0 | 用户管理 | 核心业务依赖 |
| P0 | 角色管理 + 权限分配 | 权限控制基础 |
| P1 | 部门管理 | 组织架构核心 |
| P1 | 数据字典 | 系统配置基础 |
| P2 | 日志管理 | 审计合规 |
| P2 | 三员管理 | 安全合规 |

## 4. 测试执行流程

### 4.1 执行顺序
1. **环境准备**：启动后端（8080）、前端（3000），确认数据库已初始化
2. **认证管理**：验证登录/登出，获取有效 token
3. **部门管理**：部门 CRUD → 树形视图 → 领导设置
4. **用户管理**：用户 CRUD → 角色授权 → 详情查看
5. **角色管理**：角色 CRUD → 权限分配
6. **数据字典**：类型 CRUD → 字典项 CRUD
7. **日志管理**：触发操作后查看日志 → 导出
8. **三员管理**：查看三员列表 → 审计日志

### 4.2 通过标准
- P0 用例：**100% 通过**
- P1 用例：**≥ 95% 通过**
- P2 用例：**≥ 90% 通过**
- 无 P0/P1 级别遗留缺陷

## 5. 缺陷等级定义

| 等级 | 定义 | 示例 |
|------|------|------|
| 致命 | 系统崩溃/数据丢失 | 登录后白屏、删除部门导致数据库异常 |
| 严重 | 核心功能不可用 | 创建用户失败、权限分配不生效 |
| 一般 | 功能异常但有绕过方案 | 日志导出不含时间筛选、排序不生效 |
| 轻微 | UI 展示问题 | 对齐、文案、图标显示异常 |
