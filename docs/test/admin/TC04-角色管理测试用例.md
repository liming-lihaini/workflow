# TC04 - 角色管理测试用例

## 模块信息
- **页面路径**：flow-web/src/views/system/role.vue
- **后端接口**：RoleController（/api/v1/system/roles/*）+ PermissionController（/api/v1/system/permissions/*）
- **API 文件**：flow-web/src/api/system.js
- **优先级**：P0
