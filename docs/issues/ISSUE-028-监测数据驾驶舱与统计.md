## 1. 功能描述

本 Issue 是数据呈现与决策支撑层，覆盖「工作台待办 → 档案台账 → 统计报表 → 可视化大屏」：

1. **工作台首页（6.1）**：按角色聚合待办（待派单/待收样/待检测/待审核/待签发/待复测），点击直达。
2. **档案台账（5.8）**：七类合规台账（委托/采样/样品/检测/质控/报告/留样），可查可导出，满足 CMA 溯源。
3. **统计报表（5.8）**：经营/业务统计（订单量/营收/客户占比/超标率）、人员绩效，导出 Excel/PDF。
4. **可视化大屏（6.10）**：实验室管理深色主题大屏，实时展示业务态势、预警、超标分布。

**范围边界**：数据来源于 022~027；权限可见性由 030 控制。

## 2. 业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| BR-028-01 | 角色待办 | 工作台待办按角色过滤（权限矩阵），客户账号仅见本单位 |
| BR-028-02 | 台账溯源 | 七类台账记录可逐层下钻溯源（委托→订单→样品→检测→报告） |
| BR-028-03 | 导出留痕 | 台账/报表导出动作全部写审计（WORM），涉密数据需单独授权 |
| BR-028-04 | 统计缓存 | 大屏/报表走 t_stats_cache 定时刷新，避免实时重算 |
| BR-028-05 | 性能口径 | 百万级数据 P95 查询 ≤3s，导出异步+进度 |
| BR-028-06 | 大屏主题 | 可视化大屏采用深色主题，与 PC 端浅色规范区分 |

## 3. 状态机

本 Issue 为**查询/展示型**，无业务状态机。底层数据状态机由 022~027 各自定义（委托/订单/样品/批次/报告等）。大屏仅消费各状态快照。

---

## 4. 业务流程

```
[全业务数据(022~027)] → [统计缓存 t_stats_cache 定时聚合]
       │
       ├─▶ [工作台:角色待办聚合] ──点击──▶ 各业务处理页
       ├─▶ [档案台账:七类合规台账] ──下钻/导出──▶ 溯源 + 审计
       ├─▶ [统计报表:经营/绩效] ──导出──▶ Excel/PDF
       └─▶ [可视化大屏:实时态势] ──轮询──▶ 监控大屏
```

**上游**：022~027 全模块。
**下游**：无（终端展示层）。

---

## 5. 操作流程

**全员（工作台）**
1. 登录后进入工作台，查看角色化待办卡片，点击直达处理页。

**档案管理员 / 各角色（台账）**
1. 「档案台账」选择台账类型（委托/采样/样品/检测/质控/报告/留样）。
2. 筛选+查询，逐层下钻溯源；导出 Excel/PDF（导出留痕）。

**管理者（统计/大屏）**
1. 「统计报表」查看经营/业务/绩效，导出。
2. 「可视化大屏」投屏查看实时业务态势、预警、超标分布（深色主题，自动轮询）。

---

## 6. 界面设计

PRD 规范：PC 端浅色（生态绿主色）；大屏独立深色主题。

- **工作台首页（图 6-1）**：顶部统计卡（待办汇总）+ 角色化待办列表 + 快捷入口。
- **档案台账**：七类台账 Tab 切换，统一「筛选条 + 表格 + 分页」，支持下钻抽屉。
- **统计报表**：图表（柱状/饼图）+ 表格，导出按钮（Excel/PDF）。
- **可视化大屏（图 6-11）**：深色背景（深蓝/黑），多面板（业务总量 KPI、实时订单流、超标分布地图、预警清单、人员绩效排行），自动轮询刷新，标题生态绿点缀。

## 7. 接口设计

| 接口 | 方法/路径 | 说明 |
|------|-----------|------|
| 工作台待办 | `GET /api/v1/dashboard/todos?role=` | 角色化待办 |
| 档案台账 | `GET /api/v1/archive/{type}?filter=` | 七类台账(type:entrust/order/sample/test/qc/report/retain) |
| 台账下钻 | `GET /api/v1/archive/trace?bizId=` | 溯源链 |
| 统计报表 | `GET /api/v1/stats/business` · `/performance` | 经营/绩效 |
| 报表导出 | `POST /api/v1/stats/export` | 异步生成+进度 |
| 大屏数据 | `GET /api/v1/screen/realtime` | 大屏实时聚合（读缓存） |

## 8. 数据表结构设计

**档案（5.8）**

| t_archive | id, biz_type(业务类型), biz_id(业务ID), title(档案标题), file_meta_id(文件ID), retain_years(保管年限), archived_by, archived_at | 电子档案（WORM 归档） |

| 视图/表 | 关键字段 | 说明 |

| v_ledger_order | 订单维度视图（订单/点位/状态/派单） | 采样台账 |
| v_ledger_sample | 样品维度视图（条码/类型/状态/留样） | 样品台账 |
| v_ledger_test | 检测维度视图（批次/项目/结果/超标） | 检测台账 |
| v_ledger_qc | 质控维度视图（活动/计划/结论） | 质控台账 |
| v_ledger_report | 报告维度视图（编号/状态/签发） | 报告台账 |
| v_ledger_retain | 留样维度视图（库位/到期/状态） | 留样台账 |
| t_stats_cache | id, stats_key(统计键), stats_val(JSON), computed_at(计算时间) | 统计缓存（定时刷新） |

> 说明：视图为只读聚合，底层数据来自 022~027 各表；导出动作经 ISSUE-030 审计 WORM。
