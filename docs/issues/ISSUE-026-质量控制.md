## 1. 功能描述

本 Issue 是质量体系的物资与计划底座，覆盖「物资闸门 + 闭环质控 + 质控计划/能力验证」三块：

1. **仪器设备与标准物资管理（5.5）**
   - 仪器台账（校准有效期、状态机：在用→校准临期→强制停用→校准/维修→恢复/报废）。
   - 标准物质、试剂、耗材台账；到期预警闸门。
   - 危化品台账（采购/领用/报废固定审批状态机）。
   - **物资闸门**：派单/检测引用过期物资时阻断（联动 023/025）。
2. **闭环质控（5.6）**：数据锁定的异常说明/复测管理（与 025 协同）。
3. **质控计划与能力验证（5.12）**
   - 年度/季度质控计划（固定审批状态机）。
   - 监控活动登记（空白/平行/加标回收/留样复测），与 025 批次质控联动。
   - 能力验证/实验室间比对/重复性试验（G6），纳入人员/方法能力画像。

## 2. 业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| BR-026-01 | 校准闸门 | 设备校准过期自动置「强制停用」，派单/检测引用被拦截（029 规则引擎） |
| BR-026-02 | 临期预警 | 校准/标物/试剂/留样到期前定时任务写 t_alert（站内信/微信/短信） |
| BR-026-03 | 危化品审批 | 危化品采购/报废走固定审批状态机，记录不可删 |
| BR-026-04 | 计划驱动 | 监控活动须归属质控计划，临时活动标注 |
| BR-026-05 | 能力联动 | 能力验证/比对不合格触发 030 资质复核，写入能力画像影响派单/录入闸门 |
| BR-026-06 | 留痕 WORM | 物资/计划/验证写操作均经审计（5.9/5.10），不可删改 |
| BR-026-07 | 标物效期 | 标准物质过期不可用于检测，领用校验效期 |
| BR-026-08 | 复测闭环 | 025 锁定的异常须在本模块登记复测处置结论 |

## 3. 状态机

### 3.1 仪器状态机（5.5）
| 当前状态 | 事件 | 目标状态 | 守卫 |
|----------|------|----------|------|
| 在用 | 临期扫描 | 校准临期 | 距校准到期 ≤ N 天 |
| 校准临期 | 到期未校准 | 强制停用 | 超校准有效期，阻断引用 |
| 校准临期 | 校准完成 | 恢复启用 | 校准合格 |
| 强制停用 | 校准/维修 | 恢复启用 | 合格证明 |
| 在用 | 报废 | 报废 | 审批通过，记录保留 |

### 3.2 危化品审批状态机（5.5）
| 当前状态 | 事件 | 目标状态 | 守卫 |
|----------|------|----------|------|
| 在库 | 申请领用/报废 | 待审批 | 用途/数量合规 |
| 待审批 | 审批通过 | 已领用/已报废 | 安全员确认 |
| 待审批 | 驳回 | 在库 | 必填意见 |

### 3.3 质控计划状态机（5.12）
| 当前状态 | 事件 | 目标状态 | 守卫 |
|----------|------|----------|------|
| 草稿 | 提交审批 | 审批中 | 计划项非空 |
| 审批中 | 审批通过 | 执行中 | 质量负责人确认 |
| 审批中 | 驳回 | 草稿 | 必填意见 |
| 执行中 | 活动完成 | 已完成 | 活动记录齐全 |

## 4. 业务流程

```
[物资入库(仪器/标物/试剂/危化品)] → 台账 + 校准/效期
       │
       ├─闸门──▶ [派单(023)/检测(025) 引用校验] ← 过期阻断
       │
       └─到期──▶ [预警 t_alert] → 推送(站内信/微信/短信)
       
[质控计划(5.12)] → 审批执行中 → [监控活动登记] ─联动─▶ 025 批次质控
                                                    │
[能力验证/比对/重复(G6)] ──不合格──▶ 030 资质复核 ──▶ 影响派单/录入闸门
```

**上游**：025 检测批次异常、023 派单物资引用。
**下游**：物资闸门反向约束 023/025；能力画像约束 030 资质。

## 5. 操作流程

**档案管理员 / 设备管理员（5.5）**
1. 「物资仪器 → 仪器台账」新增仪器，填校准周期；临期/到期系统自动标色+预警。
2. 标物/试剂/耗材入库登记效期；危化品采购/报废走审批流。
3. 处理预警：校准/报废处置，状态机流转。

**质量负责人（5.12）**
1. 「质控计划」编制年度/季度计划（类型/项目/责任人/频次），提交审批。
2. 审批通过 → 执行中；按计划登记监控活动（关联检测批次或独立登记）。
3. 登记能力验证/实验室间比对/重复性试验结果，查看人员/方法能力画像。
4. 不合格结果触发资质复核（转 030）。

**检测员（质控活动）**
1. 按计划执行空白/平行/加标回收/留样复测，登记结果（◐ 部分权限）。

## 6. 界面设计

PRD 规范：生态绿主色；仪器台账校准预警用橙/红；状态 Tag。

- **仪器台账（图 6-9）**：表格含校准日期/下次校准/状态 Tag（在用绿、临期橙、停用红）；临期行高亮；校准预警铃铛。
- **标物/试剂/危化品**：效期倒计时列，临期橙、过期红；危化品审批抽屉。
- **质控计划**：甘特/列表（按年/季），计划项编辑器；执行进度卡。
- **能力验证台账**：外部机构/项目/结果/证书；实验室间比对看板；人员/方法能力画像卡片（合格率/偏差趋势）。
- **监控活动录入**：表单关联 t_test_batch 或独立登记，结果合格/不合格 Tag。
