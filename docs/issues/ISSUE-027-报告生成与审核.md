## 1. 功能描述

本 Issue 是检测结果向客户/监管交付的出口，实现「报告编制 → 三级审核（自审/审核/签发）→ PDF 归档 → 上报」完整链路：

1. **报告编制**：基于已锁定检测批次（025）自动汇总数据生成报告草稿，套用模板。
2. **三级审核（5.7）**：自审（编制人账号确认）→ 审核（复核+意见，可驳回）→ 签发（质控核查结论，可驳回）。
3. **PDF 生成与归档**：签发后生成 PDF 落服务器文件系统（t_file_meta，WORM），推送客户。
4. **版本管理**：报告修改走版本变更，旧版保留可查，新版本重新走三级审核。
5. **监管上报**：可上报监管平台（集成配置 022）。

**范围边界**：报告中的数据来自 025；审核人/签字人权限来自 030。

## 2. 业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| BR-027-01 | 数据来源锁定 | 报告仅可引用「已锁定」批次数据，未锁定不可编制 |
| BR-027-02 | 三级顺序 | 自审→审核→签发 顺序不可逆，前级未过不可进下一级 |
| BR-027-03 | 驳回留痕 | 审核/签发驳回必填意见，退回编制人修改 |
| BR-027-04 | 账号归属 | 三级均以登录账号 + 审计归属，无图形电子签名 |
| BR-027-05 | 版本不可改 | 已签发报告正文 WORM，修改须新版本重走审核 |
| BR-027-06 | PDF 受控 | 签发后 PDF 落文件系统只读+哈希，防篡改 |
| BR-027-07 | 超标标注 | 报告内超标项同步标红 + ▲（继承 025 标记） |
| BR-027-08 | 可见性 | 客户账号仅可下载本单位报告（权限矩阵） |

## 3. 状态机

### 报告审核状态机（5.7）
| 当前状态 | 事件 | 目标状态 | 守卫 |
|----------|------|----------|------|
| 编制中 | 自审通过 | 自审通过 | 编制人账号确认 |
| 自审通过 | 提交审核 | 审核中 | 数据完整 |
| 审核中 | 审核通过 | 签发中 | 复核无误 |
| 审核中 | 驳回 | 编制中 | 必填意见，退回修改 |
| 签发中 | 签发 | 已签发(归档) | 质控核查结论通过，生成 PDF |
| 签发中 | 驳回 | 编制中 | 必填意见 |
| 已签发 | 版本变更 | 编制中(新版本) | 旧版保留，新版本重走审核 |

## 4. 业务流程

```
[批次锁定(025)] → [报告编制:套模板汇总数据] → 自审(账号确认)
       │                                        │
       │                                    提交审核
       ▼                                        ▼
[归档:PDF落盘+推送客户+可上报] ← 签发 ← 审核(可驳回退回)
       │
       ▼
[监管上报(可选,集成配置)]
```

**上游**：ISSUE-025 批次「已锁定」。
**下游**：归档驱动 ISSUE-028 档案台账/统计；上报依赖 022 集成配置。

## 5. 操作流程

**检测员 / 编制人**
1. 「报告管理 → 新建报告」，选已锁定批次，系统套模板汇总数据生成草稿。
2. 校对数据（超标项标红），自审确认 → 状态「自审通过」提交审核。

**审核员**
1. 「报告管理 → 待审核」打开报告，复核数据/结论/格式。
2. 通过 → 提交签发；不通过 → 填意见驳回退回编制人。

**授权签字人**
1. 「报告管理 → 待签发」核查质控结论与合规性。
2. 签发 → 系统生成 PDF 落盘归档、推送客户；不通过 → 驳回退回。

**档案管理员**
1. 「报告管理 → 已归档」查看/导出；如需修改，发起版本变更（新版本重走审核）。

## 6. 界面设计

PRD 规范：生态绿主色；报告审核页三级流转用步骤条；状态 Tag。

- **报告审核页（图 6-10）**：顶部三级步骤条（自审/审核/签发，当前态高亮）；左侧报告预览（PDF 或 HTML 渲染），超标项红标 ▲；右侧审核意见输入 + 通过/驳回按钮 + 溯源抽屉（操作记录）。
- **报告列表**：统计卡（编制中/待审核/待签发/已签发）+ 筛选 + 表格；版本标记。
- **模板配置**：报告模板编辑器（仅管理员 ◐ 模板配置）。

## 8. 数据表结构设计

| 表 | 关键字段 | 说明 |
|----|----------|------|
| t_report | id, report_no(报告编号,编号引擎), entrust_id, order_id, batch_ids(JSON,锁定批次), template_id(模板), status(编制中/自审通过/审核中/签发中/已签发), compiler_id(编制人), signer_id(签字人), issued_at(签发时间), file_meta_id(PDF文件ID,引用t_file_meta) | 报告主表（状态机核心） |
| t_report_review | id, report_id, stage(自审/审核/签发), reviewer_id, opinion(意见), result(通过/驳回), review_at | 三级审核记录（不可删） |
| t_report_version | id, report_id, version(版本号), prev_version_id, change_note(变更说明), status, created_at | 报告版本管理（旧版保留） |

> 关联：t_report.batch_ids → t_test_batch（须已锁定）；t_report.file_meta_id → t_file_meta（PDF WORM）；审核人/签字人权限见 ISSUE-030。
