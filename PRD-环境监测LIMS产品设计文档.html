1. 产品概述

1.1产品定位

环境监测 LIMS 是一套「业务全线上化 + 全程可溯源 + 合规强管控」的实验室信息管理系统。产品以采样订单为业务主线、以样品为数据主键、以质控规则为流程闸门，把纸质台账、Excel 记录、线下审批全部搬到线上，并沉淀为可一键导出的 CMA 评审资料。

1.2核心产品目标（对应 BRD 建设目标）

产品目标可衡量指标（验收口径）
业务全线上化十大模块全部线上运行，全业务闭环可演示，无线下断点
全链路溯源任意报告可在 3 次点击内反查到原始数据、采样记录、现场照片
合规强管控质控不合格数据 100% 被系统锁定，无法进入报告；操作日志不可篡改
降本增效报告编制耗时降低 ≥60%；台账自动生成率 100%
风险预警校准/标物/试剂/留样到期、数据超标 5 类预警自动触发率 100%
数据互通支持仪器数据自动采集、监管平台标准接口上报

1.3业务范围

覆盖监测类别：地表水 / 地下水 / 生活污水 / 工业废水 / 有组织废气 / 无组织废气 / 土壤 / 沉积物 / 固废 / 噪声 / 振动 / 底泥等。

2. 用户角色与使用场景

业务接单员建立客户档案、创建委托单、报价合同、收费对账、生成采样订单
外勤采样员微信小程序接收任务、填写现场记录、蓝牙打印样品条码、拍照存证、提交送检
样品管理员扫码收样核验、分样流转、留样库管理、到期销毁审批
检测员录入/采集原始数据、执行实验室质控、处理异常复测、发起报告自审
审核员复核检测数据与质控记录、审核报告、驳回并填写意见
授权签字人报告批准签发、电子签章、超标数据确认
档案/物资管理员仪器校准、标物试剂危化品管理、电子档案与合规台账维护
系统管理员 / 客户账号权限配置、字典维护、审计日志；客户在线查进度、下载报告
角色与权限的完整对应关系见 第 7 章权限矩阵；人员资质与检测项目强绑定（无授权不可录入对应项目数据）是硬性合规约束。

3. 总体业务流程

3.1主流程（订单状态机）

客户委托→ 技术室确认→ 采样订单待派单→ 采样执行中→ 样品送检 / 收样→ 实验室检测中→ 报告编制→ 三级审核签发→ 归档 / 上报

3.2关键流程规则

  • 状态不可跳跃：订单状态只能沿状态机正向流转；审核驳回沿固定回退路径（签发→审核→检测自审），每次驳回必填意见并留痕；
  • 质控闸门：「实验室检测中 → 报告编制」的流转以质控判定通过为前置条件，质控不合格自动锁定相关数据；
  • 资质闸门：数据录入前校验「人员-项目-方法」授权关系，无授权直接拦截；
  • 物资闸门：过期标物/试剂、校准过期仪器在任务关联时被系统禁用；
  • 双向溯源：委托单号、订单号、样品条码、报告编号四级编码贯穿全程，支持正/反向一键追溯。

6.11检测作业指导书(SOP)管理

功能点需求描述优先级
SOP 编制与维护按「监测类别 × 检测项目 × 标准方法」组织 SOP，描述采样/检测操作步骤、仪器、试剂、质控要求；支持多版本P1
受控发布与版本管理SOP 经技术负责人审核后发布为受控文件；旧版置作废并保留溯源，新版本发布后旧版不得被新任务引用P1
方法关联与引用SOP 关联标准方法，采样（§6.4）与检测录入（§6.7）时可调阅对应 SOP 作为操作依据P1
SOP 受控查阅按监测类别/项目/方法检索在用 SOP；正文文件只读防篡改，权限受控P2
设计说明：
  1. SOP 作为受控技术文件，正文落服务器文件系统（只读+哈希），修改生成新版本而非覆盖，满足受控文件不可篡改（对应 TRD 5.11）；
  2. 一个标准方法可有多份 SOP（如不同介质），由类别区分；发布须经技术负责人审核，草稿不可直接用于指导检测；
  3. 与标准库联动，通过方法唯一关联，避免操作依据与现行标准脱节。

6.12质量控制计划与能力验证管理

功能点需求描述优先级
质量控制计划按年度/季度编制质控计划，明确监控类型（空白/平行/加标回收/留样复测等）、覆盖项目、责任人与频次P1
监控活动登记按计划执行监控活动并登记结果，与 §6.7 批次级质控判定联动P1
能力验证 / 比对登记外部能力验证、实验室间比对结果（机构/项目/结果/证书），纳入能力画像P1
重复性试验登记内部重复性试验结果（首次值/重复值/偏差/结论），支撑方法稳定性评估P2
人员/方法能力画像汇总能力验证/比对/重复试验结果，生成人员与方法的检测能力画像，不合格触发资质复核P1
设计说明：
  1. 质控计划审批后进入执行，监控活动须归属计划（临时活动可标注）；计划/活动状态机固定审批（对应 TRD 5.12）；
  2. 能力验证/实验室间比对不合格触发人员资质复核（§7 权限矩阵），结果写入人员/方法能力画像，影响派单与录入资质闸门；
  3. 与 §6.7 检测质控、§7 人员资质构成「计划—执行—判定—能力」闭环，满足 CMA 质量体系要求。

9. 合规硬约束与交付验收标准

9.1合规硬约束（系统级强制，不可配置绕过）

  • 全流程操作留痕，满足 CMA 数据溯源要求（日志不可删改）；
  • 质控流程不可跳过，质控不合格数据禁止出具正式报告（系统锁定）；
  • 人员资质与检测项目强绑定，无授权不可开展对应检测；
  • 仪器/标物/危化品有效期强制预警，过期物资禁止投入业务使用；
  • 采样、收样、检测、审核、批准流程不可逆驳回，所有修改记录可查；
  • 电子记录、电子签名完整可追溯，可直接用于资质评审、环保督查。
