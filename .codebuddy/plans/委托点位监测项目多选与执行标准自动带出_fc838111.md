## 用户需求

委托管理中，新建委托时，在点位信息中添加点位，将"检测项目"从单选改为多选。选择监测项目后，自动带出对应每个项目的执行标准，并确保编辑回显和数据保存正确。

## 产品概述

当前委托管理的点位信息表格中，"检测项目"字段为单选下拉。需要改为多选，选择多个监测项目后，自动汇总并展示对应的执行标准（去重拼接）。

## 核心功能

- 检测项目下拉改为多选模式（`mode="multiple"`）
- 选择后自动带出执行标准（多项目去重后逗号拼接）
- 编辑委托时正确回显已选的多个监测项目
- 后端无需改动（已支持逗号分隔的 factors 存储格式）

## 技术栈

- 前端：Vue 3 + Ant Design Vue（a-select multiple 模式）
- 后端：Spring Boot + MyBatis-Plus（factors 字段为 TEXT 类型，逗号分隔存储，无需改动）

## 实现方案

### 改动范围

仅前端 `Entrust.vue` 单文件改动，后端无改动。

### 具体改动点（`d:/source_code/workflow/flow-web/src/views/ems/base/Entrust.vue`）

**1. 检测项目下拉改为多选（第174-183行）**

将 `a-select` 添加 `mode="multiple"`，并修改 `@change` 事件逻辑：

- 多选时 `@change` 返回的是选中值数组
- 遍历选中项，从 `configItemOptions` 中找到每项的 `standard` 属性
- 去重后拼接为逗号分隔字符串，写入 `record.standardCode` 和 `record.standardName`

**2. 回显逻辑修正（第494行）**

`loadEntrustDetail` 中 `factors` 回显：

- 当前：`factors: p.factors ? String(p.factors).split(',')[0] : undefined`（只取第一个）
- 改为：`factors: p.factors ? String(p.factors).split(',') : []`（返回完整数组）

**3. `addPoint()` 初始化（第430行）**

`factors` 初始值从 `undefined` 改为 `[]`（空数组），适配多选模式。

**4. 列宽调整（第319行）**

检测项目列宽度从 200 调整为 280，执行标准列从 220 调整为 260，适应多选 tag 展示。

**5. 监测类别变更时的重置逻辑（第171行）**

切换监测类别时，`factors` 重置为空数组 `[]` 而非 `undefined`，`standardCode`/`standardName` 清空。

### 执行标准汇总逻辑

```javascript
// 多选 @change 事件处理
@change="(vals) => {
  const opts = configItemOptions(record.pointType)
  const standards = [...new Set(
    vals.map(v => { const o = opts.find(s => s.value === v); return o ? o.standard : '' }).filter(Boolean)
  )]
  record.standardCode = standards.join(', ')
  record.standardName = standards.join(', ')
}"
```

### 数据流

```
用户多选检测项目 → @change 返回 ["pH值","COD","氨氮"]
→ 从 configItemOptions 查找每项的 standard 属性
→ 去重 → ["GB 3838-2002", "HJ 828-2017"]
→ 拼接为逗号字符串写入 record.standardCode
→ 保存时 join(',') 存入后端 factors 字段
→ 编辑回显时 split(',') 还原数组
```

## 实现要点

- **后端无需改动**：`handleSave` 已有 `Array.isArray(p.factors) ? p.factors.join(',')` 逻辑，后端 factors 为 TEXT 字段存储逗号分隔字符串
- **去重处理**：多个监测项目可能引用同一执行标准，需 `Set` 去重后再拼接
- **回显兼容**：旧数据 factors 为逗号分隔字符串，`split(',')` 可正确还原为数组
- **空值处理**：多选清空时返回空数组 `[]`，`join(',')` 结果为空字符串，与后端兼容
