## 样式系统概述

本项目包含两个独立的前端模块，采用不同的技术栈但共享统一的视觉设计语言：

- **flow-web**（Vue3 管理后台）：基于 Ant Design Vue + CSS 变量
- **flow-designer**（React 流程设计器）：基于 ReactFlow + 原生 CSS

## 设计令牌（Design Tokens）

两个模块都使用 CSS 自定义属性定义统一的设计令牌，位于各自的全局样式文件中：

### 颜色体系
- 主色：`--color-primary: #1677ff`（蓝色系）
- 语义色：success(#00b42a)、warning(#ff7d00)、danger(#f53f3f)、info(#86909c)
- 文字色：title(#1d2129)、content(#4e5969)、placeholder(#86909c)、disable(#c9cdd4)
- 背景色：page(#f5f7fa)、card(#ffffff)、hover(#f2f3f5)

### 间距与圆角
- 间距阶梯：xs(4px)、sm(8px)、md(16px)、lg(24px)、xl(32px)
- 圆角：sm(4px)、md(6px)、lg(8px)

### 字体与排版
- 字体族：Inter, "Microsoft YaHei", sans-serif
- 基础字号：14px

## 样式组织方式

### flow-web（Vue3 管理后台）
- **全局样式入口**：`src/styles/variables.css` 定义所有设计令牌和全局组件样式
- **组件样式**：使用 Vue scoped style，每个组件独立管理样式
- **UI 框架**：Ant Design Vue 4.x，通过 `ant-design-vue/dist/reset.css` 引入基础样式
- **布局系统**：基于 Ant Design Layout 组件的 BasicLayout.vue 提供标准后台布局

### flow-designer（React 流程设计器）
- **全局样式**：`src/index.css` 包含完整的设计令牌和组件样式
- **第三方库样式**：直接引入 `reactflow/dist/style.css`
- **组件样式**：使用 CSS Modules 或全局类名，按功能模块组织

## 通用样式模式

### 卡片容器
```css
.card-wrap {
  background: var(--bg-card);
  border-radius: var(--radius-lg);
  box-shadow: 0 1px 4px rgba(0, 0, 0, 0.08);
  padding: var(--gap-lg);
}
```

### 页面头部
```css
.page-header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  margin-bottom: var(--gap-md);
}
```

### 按钮交互
- 点击缩放效果：`transform: scale(0.98)`
- 悬停状态：使用主题色深色变体
- 过渡动画：0.2s 平滑过渡

### 表单输入
- 聚焦边框：`border-color: var(--color-primary)`
- 圆角：var(--radius-sm)
- 内边距：var(--gap-sm)

## 响应式策略

项目主要面向桌面端管理后台，未实现移动端适配。布局采用固定宽度侧边栏（220px 折叠为 64px）+ 自适应内容区的传统后台布局模式。

## 开发约定

1. **优先使用 CSS 变量**：所有颜色、间距、圆角都应引用设计令牌
2. **组件样式隔离**：Vue 组件使用 scoped，React 组件使用独立 CSS 文件
3. **保持视觉一致性**：新组件应遵循现有的间距、颜色和交互模式
4. **避免硬编码值**：不要直接使用像素值，优先使用设计令牌
5. **第三方库覆盖**：通过全局样式文件覆盖 Ant Design 和 ReactFlow 的默认样式
