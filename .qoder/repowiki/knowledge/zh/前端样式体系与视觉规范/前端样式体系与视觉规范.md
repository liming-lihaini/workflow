## 系统概述

该项目包含两个独立的前端应用，采用不同的技术栈但共享一致的视觉设计语言：
- **flow-web**：Vue3 + Ant Design Vue 管理后台
- **flow-designer**：React + ReactFlow 流程可视化设计器

## 设计令牌（Design Tokens）

两个项目均使用 CSS 自定义属性定义统一的设计令牌，位于各自的全局样式文件中：
- `flow-web/src/styles/variables.css`：管理后台主题变量
- `flow-designer/src/index.css`：设计器主题变量

核心令牌包括：
- **色彩体系**：主色 `--color-primary: #1677ff`、成功/警告/危险/信息色
- **文字层级**：标题 `--text-title`、内容 `--text-content`、占位符 `--text-placeholder`
- **背景系统**：页面背景 `--bg-page`、卡片背景 `--bg-card`、悬停背景 `--bg-hover`
- **间距规范**：从 `--gap-xs: 4px` 到 `--gap-xl: 32px` 的六级间距
- **圆角规范**：`--radius-sm: 4px`、`--radius-md: 6px`、`--radius-lg: 8px`

## 样式架构模式

### 管理后台（flow-web）
- **组件库**：Ant Design Vue 4.x，通过 `import 'ant-design-vue/dist/reset.css'` 引入基础样式
- **全局样式**：在 `main.js` 中引入 `./styles/variables.css` 作为全局样式入口
- **布局模式**：基于 `.card-wrap`、`.page-wrap`、`.page-header` 等通用容器类
- **交互增强**：按钮点击缩放效果、输入框聚焦边框色、表格行悬停高亮

### 流程设计器（flow-designer）
- **组件库**：ReactFlow 11.x 用于流程图可视化，配合 @reactflow/* 插件生态
- **自定义样式**：大量原生 CSS 类覆盖 ReactFlow 默认样式
- **布局模式**：三栏布局（工具栏 + 节点面板 + 画布 + 配置面板）
- **节点样式**：自定义 `.flow-node` 类，支持选中状态、网关特殊形状（菱形）

## 响应式策略

- 采用 CSS Grid/Flexbox 弹性布局
- 设计器使用固定宽度侧边栏（节点面板 200px，配置面板 500px）
- 画布区域自适应剩余空间（`flex: 1`）
- 移动端适配主要通过媒体查询和相对单位实现

## 开发规范

1. **颜色使用**：优先使用 CSS 变量而非硬编码颜色值
2. **间距规范**：严格遵循 4px 倍数的间距系统
3. **组件样式**：Ant Design 组件通过 CSS 变量覆盖主题，避免直接修改组件样式
4. **动画过渡**：统一的 0.2s 过渡时间，按钮点击使用 scale(0.98) 反馈
5. **字体规范**：Inter, "Microsoft YaHei", sans-serif 字体栈

## 关键文件

- 管理后台主题变量：`flow-web/src/styles/variables.css`
- 设计器全局样式：`flow-designer/src/index.css`

- 设计器入口：`flow-designer/src/main.jsx`
