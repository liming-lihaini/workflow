本项目包含两个独立的前端应用，各自维护一套基于 CSS 变量（CSS Custom Properties）的轻量级设计系统，整体风格统一但实现相互独立。

**1. 样式架构与工具链**
- flow-web（Vue3 管理后台）：基于 Vite + Vue 3 + Ant Design Vue 4，入口 `src/main.js` 全局引入 `ant-design-vue/dist/reset.css` 作为基础样式重置，并通过 `./styles/variables.css` 注入全局 CSS 变量。
- flow-designer（ReactFlow 可视化设计器）：基于 Vite + React 18，入口 `src/main.jsx` 直接引入 `./index.css`，组件中按需引入 `reactflow/dist/style.css` 和 `@vue-flow/core/dist/style.css`、`theme-default.css`。
- 两个项目均未使用 Sass/Less/Tailwind，纯原生 CSS + CSS 变量组织样式。

**2. 设计令牌（Design Tokens）**
两个应用的 `variables.css` / `index.css` 中定义了完全一致的 CSS 变量体系，覆盖以下维度：
- 色彩：主色 `--color-primary: #1677ff`，成功/警告/危险/信息色，文字色（标题/内容/占位/禁用），背景色（页面/卡片/悬停/登录渐变）。
- 边框与圆角：`--border-base`、`--border-light`，圆角三级 `--radius-sm(4px)`、`--radius-md(6px)`、`--radius-lg(8px)`。
- 间距：五级间距 `--gap-xs(4px)` ~ `--gap-xl(32px)`。
- 字体：统一使用 `Inter, "Microsoft YaHei", sans-serif`，基准字号 14px。

**3. 全局样式约定**
- 所有元素 `box-sizing: border-box`，body 统一设置字体、颜色与背景。
- 通用布局类：`.card-wrap`（卡片容器）、`.page-wrap`（页面容器）、`.page-header`（页面头部操作栏）。
- 表格样式：表头背景 `#f7f8fa`，行悬停背景使用 `--bg-hover`。
- 按钮交互：`.ant-btn:active` 添加 `scale(0.98)` 微缩效果。
- 输入框聚焦：边框色统一切换为 `--color-primary`。

**4. 流程设计器专属样式**
- 三栏布局：顶部工具栏 `.designer-toolbar`、左侧节点面板 `.node-palette`（固定 200px）、右侧配置面板 `.config-panel`（固定 500px）、中间画布 `.canvas-wrap`。
- 自定义节点 `.flow-node`：带阴影、选中态边框高亮；网关节点 `.flow-node.gateway` 使用 `clip-path: polygon(...)` 实现菱形。
- React Flow 覆盖：边路径、连接点、小地图等样式通过 `.react-flow__*` 选择器覆盖。
- 权限配置 UI：`.perm-field-row`、`.perm-btn-row`、`.handler-tag`、`.handler-dropdown` 等专用组件样式。

**5. 样式组织模式**
- 全局变量集中存放于 `styles/variables.css`，通过入口文件全局注入。
- 组件内样式以独立 CSS 文件形式存在（如 `index.css`），未采用 CSS Modules 或 Scoped CSS。
- 无统一的 UI 组件库封装，样式直接作用于 DOM 或通过 Ant Design Vue 主题变量覆盖。
- 两个前端应用共享同一套设计令牌，确保管理后台与设计器视觉一致性。
