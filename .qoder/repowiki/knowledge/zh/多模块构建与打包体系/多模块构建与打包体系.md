本仓库采用前后端分离的多模块结构，各子工程独立管理构建脚本，未使用统一的顶层 Makefile、Dockerfile 或 CI 流水线。

- 后端（flow-engine）：基于 Maven + Spring Boot 3.2.0，JDK 17。通过 spring-boot-maven-plugin 打包为可执行 jar；数据库使用 SQLite（jdbc:sqlite:flow_engine.db），启动时自动执行 classpath:db/schema.sql 建表，并配合 data.sql 初始化基础数据。Lombok 作为注解处理器在编译期生成代码，打包时被排除。Actuator 暴露 health/info 两个端点用于健康检查。
- 前端设计器（flow-designer）：React + ReactFlow + Vite 5，通过 package.json 的 dev/build/preview/lint 脚本驱动开发、生产构建与预览。
- 前端管理后台（flow-web）：Vue3 + Ant Design Vue + Pinia + Vite 5，同样通过 package.json 的 dev/build/preview 脚本管理生命周期。

当前仓库中未发现 Dockerfile、docker-compose、GitHub Actions、Jenkinsfile、Makefile 等容器化或 CI/CD 配置，也没有统一的版本发布脚本或跨平台构建约定。测试脚本以 PowerShell（test_*.ps1）形式散落在根目录，仅覆盖部分 API 场景。
