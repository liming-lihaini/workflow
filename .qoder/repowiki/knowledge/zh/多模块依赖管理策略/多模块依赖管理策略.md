该项目采用多模块架构，使用不同的包管理器进行依赖管理：

**后端（flow-engine）**：
- 使用Maven作为构建工具和依赖管理
- 基于Spring Boot 3.2.0父POM，继承统一版本管理
- Java 17环境，使用Lombok简化代码
- 核心依赖包括MyBatis-Plus 3.5.5、Caffeine缓存、SQLite数据库驱动
- Groovy脚本引擎用于表达式计算

**前端模块**：
- flow-designer（ReactFlow流程设计器）：使用npm + Vite，依赖reactflow、axios等
- flow-web（Vue3管理后台）：使用npm + Vite，依赖ant-design-vue、pinia、vue-router
- 两个前端模块独立管理依赖，各自维护package.json和package-lock.json

**依赖管理特点**：
- 无统一的根级依赖管理，各模块独立维护
- Maven使用properties标签集中管理版本号（如sqlite-jdbc.version）
- Spring Boot parent POM统一管理核心依赖版本
- 前端使用较新的包管理器生态（Vite 5.x、React 18、Vue 3）
- 无私有仓库配置，直接使用公共仓库
- 无依赖锁定文件的统一策略，每个模块独立管理
