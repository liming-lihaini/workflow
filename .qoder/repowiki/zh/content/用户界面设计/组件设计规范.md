## 引言
本规范面向Vue前端工程，目标是统一组件开发、复用、状态管理、样式组织、表单设计、测试与性能优化实践。结合仓库中现有前端工程（flow-web），给出可落地的命名约定、目录组织、API契约、主题变量与响应式策略，以及基于Pinia的状态管理模式和表单验证最佳实践。**最新更新**：新增了富文本编辑器组件和增强的子表格渲染器组件规范，进一步完善了表单组件的设计模式和最佳实践。

## 项目结构
当前前端工程采用按功能域划分的目录组织方式：
- src/components：通用与业务组件（RichTextEditor、SubTableRenderer等）
- src/layouts：布局组件（如 BasicLayout）
- src/views：页面级视图（dashboard、login、process、system、task等）
- src/stores：Pinia状态模块（user.js）
- src/styles：全局样式与主题变量（variables.css）
- src/api：接口封装与请求拦截（request.js、auth.js等）
- src/router：路由配置（index.js）
- src/composables：组合式函数（useResizableTable.js等）
- src/main.js、src/App.vue：应用入口与根组件

## 核心组件与约定
- 命名约定
  - 组件名使用大驼峰，文件名与组件名一致，后缀 .vue
  - 基础组件以 Base 或 U 前缀区分（如 BaseButton、UInput）
  - 业务组件按领域命名（如 ProcessDesigner、TaskList）
  - 组合式函数以 use 开头（如 useForm、usePagination、useResizableTable）
- 文件组织
  - 单文件组件（SFC）内顺序：template → script → style
  - 子组件与样式尽量就近放置；公共样式放入 styles 目录
  - 路由懒加载：views 下页面按需引入
- Props 与事件
  - Props 必须声明类型、默认值与校验规则
  - 事件命名使用小写+连字符（如 on-submit、on-change）
  - 避免在组件内部直接修改父级数据，通过 emit 通知
- 插槽与作用域插槽
  - 提供具名插槽与默认插槽，便于扩展
  - 作用域插槽暴露必要字段，保持最小暴露原则
- 组件文档
  - 每个组件配套 README 或注释说明用途、Props、Events、Slots、示例

## 架构总览
前端整体采用"路由驱动 + Pinia 状态 + API 封装"的轻量架构：
- 应用入口 main.js 初始化 Vue 实例、插件与全局配置
- App.vue 作为根容器，挂载路由与全局错误边界
- router/index.js 集中管理路由与导航守卫
- layouts/BasicLayout.vue 提供统一布局壳（侧边栏、头部、内容区）
- views/* 承载页面逻辑，组合 components/* 中的基础/业务组件
- stores/user.js 维护用户相关的全局状态
- api/* 封装 HTTP 请求，统一处理鉴权、错误码与重试
- composables/* 提供可复用的组合式函数（如表格功能）
- styles/variables.css 定义主题变量与全局样式基线

## 富文本编辑器组件规范

### 概述
富文本编辑器组件 RichTextEditor.vue 是一个功能完整的富文本编辑解决方案，专为表单字段设计。该组件提供了丰富的文本编辑功能，包括格式化、图片插入、链接管理等，同时保持了良好的性能和用户体验。

### 核心特性
- **富文本编辑**：支持加粗、斜体、下划线、字体颜色等基础格式
- **内容管理**：支持图片上传、链接插入、代码块等高级功能
- **数据绑定**：双向数据绑定，实时同步编辑内容
- **验证集成**：与表单验证系统无缝集成
- **响应式设计**：适配不同屏幕尺寸和设备
- **无障碍支持**：完整的键盘操作和屏幕阅读器支持

<script setup>

## 子表格渲染器组件规范

### 概述
子表格渲染器 SubTableRenderer.vue 是一个专门用于处理嵌套表格结构的组件，现已增强支持下拉选项功能。该组件能够渲染复杂的表格数据结构，并提供丰富的交互功能。

### 核心特性
- **嵌套表格**：支持多层级的表格结构渲染
- **下拉选项**：内置下拉选择器，支持动态选项数据
- **数据绑定**：双向数据绑定，实时更新表格内容
- **行操作**：支持行的添加、删除、排序等操作
- **列配置**：灵活的列配置和数据映射
- **验证支持**：集成表单验证，确保数据完整性

### 使用方法

#### 基础用法
```vue
<template>
  <SubTableRenderer
    v-model="tableData"
    :columns="columns"
    :options="dropdownOptions"
    @row-add="handleRowAdd"
    @row-delete="handleRowDelete"
  />
</template>

<script setup>
import { ref } from 'vue'
import SubTableRenderer from '@/components/SubTableRenderer.vue'

const tableData = ref([])
const columns = ref([
  { key: 'name', title: '名称', type: 'text' },
  { key: 'category', title: '分类', type: 'select', options: ['分类1', '分类2'] },
  { key: 'status', title: '状态', type: 'select', options: ['启用', '禁用'] }
])
const dropdownOptions = ref({
  category: [{ label: '分类1', value: 'cat1' }, { label: '分类2', value: 'cat2' }],
  status: [{ label: '启用', value: 'active' }, { label: '禁用', value: 'inactive' }]
})
</script>
```

#### 高级配置
```vue
<SubTableRenderer
  v-model="complexData"
  :columns="complexColumns"
  :options="complexOptions"
  :config="{
    maxRows: 10,
    allowDuplicate: false,
    showActions: true,
    sortable: true,
    filterable: true
  }"
  @validate="handleValidation"
  @change="handleChange"
/>
```

## 可调整大小表格组件规范

### 概述
可调整大小表格功能是项目中新增的核心表格组件能力，通过 `useResizableTable` 组合式函数提供统一的表格列宽调整体验。该功能支持用户自定义列宽、持久化存储和响应式适配。

### 核心特性
- **列宽调整**：支持鼠标拖拽调整列宽，实时预览效果
- **宽度持久化**：自动保存用户设置的列宽到 localStorage
- **响应式适配**：根据屏幕尺寸自动调整表格行为
- **性能优化**：使用防抖技术优化拖拽性能
- **无障碍支持**：键盘操作支持和屏幕阅读器兼容

### 使用方法

#### 基础用法
```javascript
import { useResizableTable } from '@/composables/useResizableTable'

const { 
  tableRef,
  columns,
  handleColumnResize,
  resetColumnWidths 
} = useResizableTable({
  storageKey: 'table-columns',
  minWidth: 50,
  maxWidth: 500
})
```

#### 在模板中使用
```vue
<template>
  <div ref="tableRef">
    <table>
      <thead>
        <tr>
          <th v-for="column in columns" :key="column.key">
            {{ column.title }}
            <div class="resize-handle" @mousedown="handleColumnResize($event, column.key)">
              <span></span>
            </div>
          </th>
        </tr>
      </thead>
      <tbody>
        <!-- 表格内容 -->
      </tbody>
    </table>
  </div>
</template>
```

### API 参考

#### useResizableTable 参数
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| storageKey | string | 'table-columns' | 本地存储键名 |
| minWidth | number | 50 | 最小列宽 |
| maxWidth | number | 500 | 最大列宽 |
| initialWidths | object | {} | 初始列宽配置 |

#### 返回值
| 方法/属性 | 类型 | 说明 |
|-----------|------|------|
| tableRef | Ref | 表格容器引用 |
| columns | ComputedRef | 计算后的列配置 |
| handleColumnResize | Function | 处理列宽调整 |
| resetColumnWidths | Function | 重置所有列宽 |
| isResizing | Ref | 是否正在调整中 |
